# ostd v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `ostd` (Stdlib-compatible extension library) and `ostd-lint` (a `.cmt`-based linter for polymorphic-comparison bugs) as two dune packages in one repo.

**Architecture:** `lib/` holds one `Ostd_<x>` module per extended Stdlib module (each starts with `include Stdlib.X`), plus new `Heap`, `Deque`, `Safe`; `Ostd` re-exports them. `lint/` is a standalone executable over `compiler-libs.common`: `main.ml` walks dirs for `.cmt`, `targets.ml` recognises polymorphic-compare idents, `classify.ml` decides how dangerous the argument type is, `report.ml` prints compiler-style diagnostics, `compat.ml` isolates compiler-version-specific constructors.

**Tech Stack:** OCaml 5.3.0, dune ≥ 3.14, alcotest, qcheck-core/qcheck-alcotest, cram tests, GitHub Actions (`ocaml/setup-ocaml@v3`).

**Spec:** `PLAN.md` (copy of the original `ostdplan.md`).

## Global Constraints

- Every extended module starts with `include Stdlib.X`; `.mli` starts with `include module type of Stdlib.X` (or `struct include` for functors). No replacement types.
- Do not add a function Stdlib 5.3 already has. `docs/gaps.md` is the source of truth; drop any candidate it marks "Stdlib".
- `open Ostd` must not change comparison semantics. Only `open Ostd.Safe` shadows comparisons.
- Library depends only on Stdlib. Linter depends only on `compiler-libs.common`. Tests may use alcotest/qcheck.
- Minimum OCaml: 5.3.0. Linter supports exactly the compiler it was built with.
- `dune-project`: `(lang dune 3.14)`, `(generate_opam_files true)`, packages `ostd`, `ostd-lint`.
- String functions operate on bytes; every String doc comment says so (module-level note is enough).
- Linter exit codes: 0 = no findings, 1 = findings, 2 = tool error.
- Diagnostic format: `File "<f>", line <l>, characters <c1>-<c2>:` newline `<Error|Warning> SLxxx [<name>]: <message>`.
- Rules: SL001 compare-functional (error), SL002 compare-abstract (warning), SL003 compare-generic (off unless `--generic`).
- Every public value has a doc comment; `dune build @doc` produces no warnings.

## Decisions (resolving the spec's open questions)

- Name stays `ostd`. Heap/Deque are persistent only.
- `zip`/`unzip`: Stdlib already has `List.combine` (raises on mismatch) and `List.split`; not duplicated (recorded in gaps.md).
- zanuda review: its `Equality` lint only suggests pattern matching for option/list/bool; nothing classifies functional/abstract operands. SL001–SL003 stay in ostd-lint.
- Linter CI runs on 5.3 only; the library also builds/tests on the latest 5.x with `--only-packages ostd`.

## Review Focus

1. Linter on a `.cmt` from a different compiler version → clear message, exit 2, no crash/backtrace. (Task 7 cram: `garbage.cmt` case.)
2. Linter on dune `_build/default` with `.cmti` and `.cmt` side by side → only `.cmt` read, no duplicate findings. (Task 7: dedupe + `.cmti` skip in walk test.)
3. Nested containers hiding a function, e.g. `(int -> int) list list` or `(int * (unit -> unit)) option` → SL001, not silently Safe because `list` was already visited. (Task 6 fixture `nested.ml`.)
4. `String.split_on ~sep:""` / `replace_all ~sub:""` → `Invalid_argument`, not an infinite loop. (Task 3 tests.)
5. `List.take (-1)`, `chunks 0`, `windows 0` → `Invalid_argument`. (Task 2 tests.)

### Task 5: Map / Set / Heap / Deque / Safe

**Files:** `lib/ostd_map.ml/.mli`, `lib/ostd_set.ml/.mli`, `lib/heap.ml/.mli`, `lib/deque.ml/.mli`, `lib/safe.ml/.mli`, `test/lib/test_containers.ml`, `test/lib/test_props.ml`, `lib/ostd.ml`.

**Produces:**
- `Ostd_map`: includes `Stdlib.Map`; shadows `module type S` (Stdlib `S` + additions) and `Make (Ord : OrderedType) : S with type key = Ord.t`. Additions (skip `of_list`, in Stdlib since 5.1): `keys : 'a t -> key list`, `values : 'a t -> 'a list`, `update_or : key -> default:'a -> ('a -> 'a) -> 'a t -> 'a t`, `merge_with : (key -> 'a -> 'a -> 'a) -> 'a t -> 'a t -> 'a t`, `find_or : key -> default:'a -> 'a t -> 'a`, `group_by : ('a -> key) -> 'a list -> 'a list t` (input order kept within groups).
- `Ostd_set`: same pattern; addition `union_all : t list -> t`, `group_by` not applicable.
- `Heap.Make (Ord) : sig type elt = Ord.t type t val empty val is_empty val size : t -> int val add : elt -> t -> t val merge : t -> t -> t val peek_min : t -> elt option val pop_min : t -> (elt * t) option val of_list : elt list -> t val to_sorted_list : t -> elt list end` — pairing heap with cached size.
- `Deque : type 'a t; empty; is_empty; length; push_front : 'a -> 'a t -> 'a t`, `push_back : 'a t -> 'a -> 'a t` (element sits on the side it is pushed to), `pop_front : 'a t -> ('a * 'a t) option`, `pop_back : 'a t -> ('a t * 'a) option`, `peek_front`, `peek_back`, `of_list`, `to_list` — banker's deque (front/back lists + lengths, rebalance by halving when one side empties).
- `Safe`: exactly the spec signature, plus `Poly` containing all six operators, `compare`, `equal`, `min`, `max`.

- [ ] Tests: unit tests per function; qcheck: `Heap.to_sorted_list (of_list l) = List.sort compare l`; Deque random op sequences vs list model; Safe: a `.ml` that applies `Safe.(=)` to strings must not compile — checked in Task 7's cram (expect type error). Fail → implement → pass → commit.

### Task 7: Linter driver, report, suppression, cram fixtures

**Files:** `lint/main.ml`, `lint/report.ml`, `test/lint/dune`, `test/lint/run.t`, `test/lint/fixtures/*.ml`.

**Produces:** CLI `ostd-lint [--generic] [--only SL001,SL002] [--format text|json] [PATH...]` (default `.`). Walk recursively, read `*.cmt` only, skip non-implementation cmts, dedupe by (file, line, col, rule), sort by file/line/col. Suppression: `[@ostd.allow "SLxxx[,SLyyy]"]` (no payload = all) on any enclosing expression or value binding; floating `[@@@ostd.allow ...]` = whole file. Unreadable/wrong-version cmt → stderr `ostd-lint: <file>: <reason> (ostd-lint was built with OCaml <ver>)`, final exit 2.

Fixtures and expected output (one per spec bullet): `funcs.ml` SL001; `maps.ml` (`Map.Make(String).t`, `Hashtbl.t`) SL002 ×2; `safe_types.ml` none; `record_map.ml` SL002; `rec_variant.ml` none, terminates; `sort_funcs.ml` (`List.sort compare` on fun list) SL001; `suppressed.ml` none; `generic.ml` none, SL003 with `--generic`; `nested.ml` SL001; `garbage.cmt` exit 2; `--only SL002` filter; `safe_reject.ml` compiled with `-open Ostd.Safe`-style local open fails to typecheck.
